## Overview

**ProjectMayhemAutomotive** builds AI-driven systems for **vehicle safety complaints, predictive diagnostics, and manufacturing quality insights**.  
The organization focuses on transforming unstructured customer feedback into **actionable engineering and manufacturing decisions**.

Our repositories together form a **closed-loop automotive intelligence pipeline** — from complaint intake to RCA/CAPA and predictive analytics.

---

## Repositories

### 🚗 Complain-Chatbot
An AI-powered chatbot for collecting and structuring vehicle safety complaints through natural language conversations.

- Intelligent extraction and validation of complaint details
- Context-aware understanding using LLMs and RAG
- Structured data generation for downstream analytics

**Tech:** Python

---

### 🧠 DataLayer
The analytical backbone of the platform, responsible for processing structured and unstructured vehicle data.

- Real-time diagnostic capabilities
- Batch-based machine learning and deep learning pipelines
- Supports predictive maintenance and failure forecasting

**Tech:** Jupyter Notebook, Python

---

### 🏭 Manufacturing-Quality-Insights-Module
An automated RCA / CAPA analytics pipeline for manufacturing and quality teams.

- Complaint clustering and defect pattern detection
- Severity and trend analysis
- Generation of professional, executive-ready reports

**Tech:** Python
